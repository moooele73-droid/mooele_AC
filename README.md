# 米記帳

簡約米色風格的個人記帳網頁，純前端（單一 `index.html`），可直接用 GitHub Pages 架設。

## 部署到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `my-ledger`）
2. 上傳 `index.html`（和這份 README）
3. 到 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`，按 Save
4. 約一分鐘後就能從 `https://<你的帳號>.github.io/my-ledger/` 開啟

> 手機上用瀏覽器開啟後，選「加入主畫面」，用起來就像 App。

## 資料存在哪裡？

- 所有紀錄、照片都存在**你自己瀏覽器的 IndexedDB**，不會上傳到 GitHub，也沒有後端伺服器。
- 換裝置或清除瀏覽器資料前，請到 **設定 → 下載完整備份**，之後在新裝置用「從備份還原」。
- 不同裝置之間不會自動同步。

## 功能

| 功能 | 說明 |
|---|---|
| 記帳 | 金額、收／支、類別、日期、付款方式、帳冊、備註、照片（自動壓縮） |
| 每月固定收支 | 「固定」分頁：依進行中／已暫停／已結束分組，顯示每月合計、期數進度、已記筆數與金額；點開可看已記入紀錄與接下來 12 期。在「固定」新增（或記帳時勾選「設為每月固定」）：每月指定日（或月底）打開網頁時自動記一筆，標示 🔁；可設開始月份與循環多久（不限／固定期數／到某個月），會顯示已記幾期，紀錄標示「🔁 第幾期/總期數」；可暫停；手動刪掉的那個月不會重記 |
| 自訂選項 | 記帳時在類別、付款方式最後按「＋ 新增…」直接輸入；在「設定」可刪除，按住 ⠿ 拖曳可調整順序 |
| 搜尋 | 頂部搜尋列可跨所有年份、帳冊找過去紀錄；多個關鍵字用空白分隔；可篩選收支、年份並排序，顯示合計 |
| 相似紀錄建議 | 輸入備註關鍵字，會列出過去相似的備註，點一下只帶入文字（不帶入金額） |
| 年份帳冊 | 每本帳冊屬於一個年份；上方選年份後可再選帳冊、某趟旅行或看全部。明細頁左右滑動可切換月份（「全年」時切換年份）。旅行帳目不屬於任何帳冊 |
| 旅行 | 點類別可看這趟旅行該類別的明細；卡片顯示支出合計，歸入旅行的收入另外列出、不扣除；可把旅行期間已匯入的紀錄批次歸入旅行；每趟旅行設定當地幣別、匯率、預算；可用外幣記帳，自動換算本位幣並顯示剩餘預算 |
| 統計 | 「月／年／自訂」切換（自訂可選起訖日期或快捷：近 7 天、近 30 天、本月、上個月、本季、今年至今），左右滑動或按 ‹ › 換期間；顯示收入、支出、結餘與分類別統計（含與上期比較）；點類別或付款方式可看細項紀錄（可依品項篩選、依金額排序）；預設不含旅行帳目（可切換） |
| 匯入 | 在「設定」最下方；CSV／TSV／JSON／Excel；自動對應欄位，可手動調整 |
| 明年 | 年份選單包含明年，可先記未來的帳；未來月份會列出「預計固定收支」（只預覽、不計入收支） |
| 清除資料 | 需輸入自訂的清除密碼（第一次會請你設定；只存雜湊值，忘記無法找回） |
| 匯出 | 完整 JSON 備份（含照片）、CSV |

### 匯入舊資料時會自動處理

- 編碼：UTF-8、Big5
- 日期：`2024-05-01`、`2024/5/1`、`20240501`、民國 `113/05/01`、`1130501`、`5/1/2024`、Excel 日期序號
- 金額：千分位、`$`、`NT$`、`元`、括號負數 `(320)`、全形數字
- 收支：有「收支」欄就用它；沒有的話，負數算支出。同一欄有正有負時，正數算收入；類別屬於收入類別也會判斷為收入。也可以使用分開的「收入」「支出」兩欄
- **對應不到的欄位不會被丟掉**，會原樣保存在該筆紀錄的「原始欄位」，在編輯畫面看得到，匯出 CSV 時也會帶出
- 報表型檔案（例如 **Monny** 匯出的 xlsx：上方有年度／月份／類別摘要，下方才是 Details 明細）會自動找到真正的明細標題列，摘要不會重複匯入；也會讀出帳本名稱
- 可指定整份檔案的幣別與匯率，並直接歸入既有旅行或自動建立新旅行（日期取明細的第一天到最後一天）
- 舊類別可以保留，也可以一鍵對應到米記帳的類別（例如 早餐／午餐／其他飲食 → 餐飲）；對應後原類別仍保存在紀錄中
- **批次匯入照片**：依檔名「日期_類別_編號」（如 Monny 匯出的 `2026-02-10_午餐_004.jpg`）配對；可限定只配對某趟旅行／帳冊／匯入來源；可選用 OCR 讀收據金額輔助配對（從 jsdelivr 載入 Tesseract.js，需要網路）；同一筆可有多張照片；手動改過的配對會固定；同一天同類別有多筆時一律請你確認；配錯的照片可在編輯紀錄時用「⇄ 移到別筆」移動或互換
- 解析失敗的列可以另外下載成 CSV，修正後再匯入
- 可略過重複紀錄（同日期、金額、收支、備註）

## 版本

目前版本 3.1。更新 GitHub 上的檔案後，可在「匯入」或「設定」頁底部確認版本；從 1.7 起，打開網頁時若 GitHub 上有更新的版本，頂端會出現「有新版本・立即更新」。

## 第三方資源

xlsx 由內建讀取器解析，不需網路；只有舊版 .xls／.ods 才會從 `cdn.sheetjs.com` 載入 SheetJS。
